orkest — Orkest's internal CLI (visible only inside the app's terminals)

`ck` is a shorter name for the same command: `ck list-tabs` == `orkest
list-tabs`. (If you already have your own `ck` alias, yours wins.)

A **tab** is a terminal/agent session (what this CLI addresses). A **pane** is
the split leaf that groups tabs — not addressed here. `list-panes`/`read-pane`
are legacy aliases of `list-tabs`/`read-tab`.

USAGE:
  orkest send      [--tab-id <id>] [--enter] <text>   type text (--enter submits)
  orkest send-key  [--tab-id <id>] <Key>...   press named key(s)
  orkest agent start <id> [--type <role>] [--tab-id <parent-tab>]
                                               report a child entering Office
  orkest agent stop  <id> [--type <role>] [--outcome <result>] [--tab-id <parent-tab>]
                                               report it finishing and leaving
  orkest activity <kind> --summary <text> [--phase <phase>] [--tab-id <id>]
                                               report provider-neutral Office activity
  orkest activity vcs --operation <op> --exit-code <n> --stdin [--tab-id <id>]
                                               normalize a confirmed Git/API/MCP result
  orkest open      [--tab-id <id>] <file>     open the file in the app's viewer
  orkest <file>                               shortcut for `open` (e.g. orkest .zprofile)
  orkest read-tab  [<label|tab-id>]           read a tab's rendered output (alias: read-pane)
  orkest read-task <task-id>                  read a task's output (even w/o tab)
  orkest list-tabs       [--json]             list active tabs (alias: list-panes)
  orkest list-workspaces [--json]             list workspaces (projects)
  orkest list-tasks      [--json]             list this workspace's tasks (Task Run)
  orkest run-task <task-id> [--profile <p>] [--restart]   start a task
  orkest stop-task <task-id>                  stop a running task
  orkest restart-task <task-id>               stop + start (same profile)
  orkest send-task-key <task-id> <key>        write an interactive key (e.g. r)
  orkest new-tab [--cwd <dir>] [--title <name>] [--split h|v]
                                               open a new terminal tab (prints its id)
  orkest close-tab [<label|tab-id>]           close a tab (default: the current
                                               one) — prints the closed tab id
  orkest new-workspace <path> [--host <host>] [--name <name>] [--json]
                                               create/open a workspace (local or remote)
  orkest new-remote-workspace --host <h> --path <p> [--name <n>] [--json]
                                               create/open a remote workspace
  orkest close-workspace [<id|path>] [--json] close a top-level workspace
  orkest rename-workspace <id|path> <name> [--json]
                                               rename a workspace in the sidebar
  orkest db <list|schema|query|run|execute>   SQL databases (see `orkest db --help`)
  orkest telemetry <cmd…> | errors | show …   run observed / query the error store (see `orkest telemetry --help`)
  orkest redis [browse] --db <conn> ...       Redis command / open key table
  orkest mongo [browse] --db <conn> [--database <name>] ...
                                               MongoDB runCommand / open browser
  orkest http <list|run> <file.http>          run HTTP requests from a .http
                                               file (see `orkest http --help`)
  orkest exec [--cwd <dir>] [--timeout <s>] [--json] [--] <command...>
                                               run a shell command via the app and
                                               print its output (see `orkest exec --help`)
  orkest browse <url> [--json]                open the built-in browser tab at
                                               <url> (system browser on Linux)
  orkest orchestrate <file.ckp> [--append]    apply a .ckp pane layout: close
                      [--json]                 the workspace tabs, then open the
                                               terminals/splits + run commands
                                               (--append keeps the open tabs)
  orkest note <add|list> <dir.notebook> ...   write/list notes in a notebook
                                               folder (see `orkest note --help`)
  orkest install-skill   [--force]            install the Claude Code skill
  orkest --help | --version

READ (read-tab / read-task):
  --lines N     how many lines (default 100, server cap 2000)
  --offset N    skip N lines from the anchor (pagination)
  --from-start  anchor at the start of the buffer (default: tail/end)
  Output is always chronological (top→bottom); flags only pick the window.
  read-tab without a target reads the CURRENT tab; a target may be a stable
  tab label or a tab-id.

TASKS (list-tasks / read-task / run-task / stop-task / restart-task / send-task-key):
  Task ids are stable per workspace: npm:<script> (package.json), flutter:run /
  flutter:test, json:<label> (.orkest/tasks.json). Discover them with
  `orkest list-tasks` — `[output]` marks tasks whose output `read-task` can
  read (ran this boot); ● marks tasks running right now. Task-output tabs in
  `list-tabs --json` also carry the task id as `taskId`.
  run/stop/restart/send-task-key drive the same runner as the Tasks panel, on
  local and remote workspaces alike. `list-tasks --json` lists each task's
  `profiles` and interactive `keys`.

DATABASES (db):
  Connections live per workspace in .orkest/databases.json (+ auto-detected
  SQLite files). Output is one JSON line — made for agents. Examples:
    orkest db list
    orkest db schema --db dev-local orders
    orkest db query --db dev-local --sql "SELECT * FROM orders LIMIT 5"
    orkest db run reports/daily.dbq
  Full reference: `orkest db --help`.

HTTP (http):
  Runs requests written in a .http file (REST Client / JetBrains syntax). The
  app renders the same file as a request tab. Output is one JSON line:
    orkest http list api/users.http
    orkest http run  api/users.http --request "Create user"
  Full reference: `orkest http --help`.

NOTEBOOKS (note):
  A folder named *.notebook is a notebook: one .md per note, frontmatter with
  title/tags. The app shows it as a single item and renders it as a notes tab.
    orkest note add notes.notebook --title "Túnel SSH" --tag relay --body -
    orkest note list notes.notebook
  Full reference: `orkest note --help`.

IDS:
  Workspace ids are opaque UUIDs — use `workspacePath` (list-tabs) / `path`
  (list-workspaces) when you need the folder on disk.

FLAGS:
  --enter         (send only) press Enter right after the text, as a separate
                  keystroke. Same as `send …` followed by `send-key … Enter`,
                  in one call.
  --focused       target the tab you are LOOKING AT, whatever it is. Resolved by
                  the app, so no id to copy. Works from outside a Orkest
                  terminal too (dictation tools, scripts): with no env inherited
                  the CLI finds the app through ~/.orkest/status.sock.

TARGET:
  --tab-id <id>   target tab (--focused wins over it). Default = $ORKEST_TAB_ID
                  (the current tab;
                  legacy fallback $ORKEST_PANE_ID). Ids (t0, t1…) reset on every
                  app boot → find them with `orkest list-tabs` before targeting
                  another tab (cross-tab).

SOCKET PERMISSIONS:
  Operation not permitted / Permission denied means the local connection was
  blocked. Request scoped approval for the same command. If the agent session
  disables approvals (never or sandbox_approval=false), change its permissions
  through the agent UI first. In Codex, resume the same conversation with:
    codex resume <session-id> --sandbox workspace-write --ask-for-approval on-request
  Then approve the CLI command. Reinstalling the app/skill cannot grant socket
  access. See orkest-cli/references/permissions.md; keep sandboxing enabled.

KEYS (send-key):
  Enter Tab Escape Space BSpace Up Down Left Right Home End
  PageUp PageDown Delete   |   C-<letter> (e.g. C-c = Ctrl+C)

NEW-TAB:
  --cwd <dir>     working directory (default: current directory)
  --title <name>  stable tab label (send/read-tab can target it by name)
  --split h|v     h (or right) = side by side; v (or down) = stacked.
                  Omit to open as a new tab in the same pane.
  Anchored at the emitting tab's pane/workspace. Prints the new tab id.

CLOSE-TAB:
  orkest close-tab [<label|tab-id>]
  Without a target it closes the CURRENT tab — the shell you are typing in
  ends with it. Closing the last tab of a split removes the split; closing the
  last tab of a workspace leaves an empty tab (same as the tab's "x" in the UI).

WORKSPACES (new-workspace / close-workspace / rename-workspace):
  orkest new-workspace <path> [--host <ssh-target>] [--name <title>] [--json]
  orkest new-remote-workspace --host <ssh-target> --path <remote-path> [--name <title>] [--json]
  Alias: `orkest open-workspace`. Adds a top-level workspace in Orkest's
  sidebar (local or remote), selects it, and ensures an initial terminal tab is
  opened. For remote workspaces, --host specifies the SSH host or ~/.ssh/config
  alias (automatically registered if not already present).
  Idempotent: if already open, selects it and returns its info. Prints the
  workspace id (or JSON object with --json).

  orkest close-workspace [<id|path>] [--json]
  Closes a top-level workspace (ends its tabs; files on disk are kept). Target
  may be a UUID, directory path, or unique name (default: current workspace).
  Prints the closed workspace id.

  orkest rename-workspace [<id|path>] <new-name> [--json]
  Updates the display title of a workspace in the sidebar. Target may be a UUID,
  directory path, or unique name (default: current workspace).

EXAMPLES:
  orkest send "echo hi" && orkest send-key Enter
  id=$(orkest new-tab --cwd ~/proj --title Worker --split h)
  orkest send --tab-id "$id" --enter "npm test"   # text + Enter in one call
  orkest close-tab "$id"                      # close it when done (or: Worker)
  ws=$(orkest new-workspace ~/proj/my-service --name "My Service")
  orkest rename-workspace "$ws" "Renamed Service"
  orkest close-workspace "$ws"
  rws=$(orkest new-remote-workspace --host workspace-vm --path /home/ubuntu/wt --name "Task 1")
  orkest send-key C-c
  orkest send --tab-id t3 --enter "ls"
  orkest .zprofile          # opens the file in the viewer (relative to tab cwd)
  orkest open ~/.gitconfig
  orkest read-tab Extension --lines 50        # last 50 lines of tab "Extension"
  orkest read-tab t4 --lines 200 --from-start
  orkest list-tasks                           # discover task ids (npm:dev, ...)
  orkest read-task npm:dev --lines 80         # tail of task "npm:dev" output
